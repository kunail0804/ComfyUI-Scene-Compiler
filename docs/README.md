# Documentation

Project documentation is maintained primarily in the
[GitHub Wiki](https://github.com/kunail0804/ComfyUI-Scene-Compiler/wiki), and the
authoritative specification is [`MASTER_SPEC.md`](../MASTER_SPEC.md) at the
repository root.

This `docs/` directory holds documentation that is **not** part of the wiki —
for example design notes, developer guides, and generated references added in
later phases.
